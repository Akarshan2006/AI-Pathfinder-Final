## 📌 About the Project

**AI PathFinder** is a full-stack AI-based web application designed to help users:
- Identify suitable career roles
- Understand required skills
- Plan learning paths
- Prepare for future job opportunities  

The system analyzes user skills and experience to generate **personalized career recommendations**.

---

## ✨ Features

✅ **Career Prediction**  
- Predicts suitable job roles based on resume and skills  

⏳ **Learning Suggestions (Coming Soon)**  
- Recommends courses and learning resources to bridge skill gaps  

⏳ **Job Matching (Coming Soon)**  
- Matches user profiles with relevant job openings

## ⚙️ Setup & Installation

### 1️⃣ Install Dependencies

From the root directory, run:

```bash
npm install
```

This will:
- Create a Python virtual environment for the backend
- Install frontend dependencies
- Install backend dependencies from `requirements.txt`

---

### 2️⃣ Run the Application

```bash
npm start
```

🔹 Frontend: `http://localhost:5173`  
🔹 Backend: `http://127.0.0.1:8000`

---

### ▶️ Individual Commands

| Command | Description |
|------|-----------|
| `npm run start:frontend` | Start frontend server |
| `npm run start:backend` | Start backend server |
| `npm run install:frontend` | Install frontend dependencies |
| `npm run install:backend` | Install backend dependencies |
| `npm run setup:backend` | Create backend virtual environment |
