# Pathfinding Algorithms Overview

This repository visualizes multiple graph search and pathfinding algorithms.

### 1. Dijkstra's Algorithm
- **Type**: Weighted, optimal.
- **Guarantee**: Guarantees the shortest path.
- **Behavior**: Explores uniformly in all directions based on distance from start.

### 2. A* Search
- **Type**: Informed, weighted.
- **Guarantee**: Guarantees shortest path if heuristic is admissible.
- **Behavior**: Uses Manhattan or Euclidean distance to guide search towards target.

### 3. Breadth-First Search (BFS)
- **Type**: Unweighted.
- **Guarantee**: Guarantees shortest path on unweighted graphs.
